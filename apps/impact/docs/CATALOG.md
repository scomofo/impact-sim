# Catalog evidence, version 2026-09-05.1

All 25 presets now carry scoped sources and an evidence status for diameter, speed, density, angle, target and water depth. `assumed` means an illustrative application choice. `estimated` means a stated observational estimate or reconstruction supports that field. No input is described as a direct measurement merely because the event is real. Unknown parameter ranges remain unknown; sensitivity percentages do not supply missing observational uncertainty.

The expandable evidence panel and assessment JSON carry the same metadata. Sources support only their individual scope, not every sentence or every physical input in a preset. Surface/geophysical structure sizes, reconstructed original craters and fragment pits are distinguished. No crater-fit percentage is an accuracy score.

The NASA-hosted archived Earth Impact Database table supplies legacy structure references for several entries. It is explicitly not a current age catalog. Projectile inputs for ancient events remain illustrative unless their individual status says otherwise. A future scientific pass should reconcile competing structure definitions and date estimates, replace remaining legacy references with event-specific primary studies, and obtain defensible input ranges before probabilistic uncertainty modeling.
