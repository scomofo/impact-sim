Orbital Suite

Space, orbital-mechanics and impact software in one workspace. Each tool is an independent app; they share the astrolab numerical toolbox.

Impacts · no build

Impact Simulator

Analytical assessment of asteroid and comet impacts on an Earth-size planet: entry, cratering, blast, thermal and seismic effects, with an optional 3D view and published benchmarks.

open directly · apps/impact
 MATLAB-style · Vite

Orbital Lab

A MATLAB-syntax command window: matrices, ode45, Kepler and Lambert solvers, Hohmann transfers, CR3BP dynamics, impact scaling and plotting.

npm run dev:lab
 Three-body · Vite

Libration

Lagrange points and halo orbits in the circular restricted three-body problem. Fling probes, switch frames, and follow JWST, SOHO, Gaia, Queqiao and Lucy.

npm run dev:libration
 Solar system · Vite

Helios

A 3D solar-system observatory with Keplerian and N-body propagation, resonance views, a 2D orrery and click-to-focus planets.

npm run dev:helios
 Rigid bodies · Vite

Stackyard

A rigid-body physics playground powered by Rapier. Drop spheres, boxes and cylinders, drag them around, and change gravity.

npm run dev:stackyard

The Vite apps link to their dist/ output; run npm run build first, or start an individual app with its dev script. The Impact Simulator runs without a build step.
